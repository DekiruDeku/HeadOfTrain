# Head of Train

The actual Godot 4.7 game project is located in `/game`.

For all UI and visual work actively use the installed skills:
- frontend-design
- game-ui-ux
- godot-ui-control
- game-feel
- godot-tweening
- godot-animation
- godot-ui-theming
- godot-shaders-basics
- godot-particles
- godot-agent-vision

Concept images are the visual source of truth.

For visual tasks:
1. Inspect the concept.
2. Inspect the existing implementation in `/game`.
3. Use the appropriate installed skills.
4. Implement natively in Godot.
5. Run the game.
6. Visually inspect the result.
7. Make a polish pass.

Do not redesign concepts into generic web/SaaS UI.
Do not break existing game logic.
