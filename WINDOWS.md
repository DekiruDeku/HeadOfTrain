# Запуск на Windows со всеми изменениями

## Самый простой способ — браузерная сборка

1. Перенесите всю папку `Head of Train`, сохранив рядом `game`, `backend`, `build/web` и `tools`.
2. Установите Python 3.10 или новее. При установке включите `Add Python to PATH`.
3. Дважды нажмите `game/start.cmd`.
4. После появления строки `Game:` откройте http://127.0.0.1:8765/ в браузере. Оставьте окно сервера открытым.
5. На главном экране нажмите «Рейтинг» (или «Профиль»). Если открывается старая версия, обновите страницу через Ctrl+F5.

`build/web` пересобрана 27.09.2026 после обновления рейтинга. `start.cmd` запускает готовую сборку и не пересобирает исходники автоматически. Godot для запуска этой сборки не нужен. Сервер сохраняет результаты в `backend/var/head-of-train.sqlite3`; не удаляйте этот файл, если хотите сохранить прогресс. Нативная игра и браузер используют разные ID игроков.

## Запуск актуальных исходников в Godot

1. Установите Godot **4.7.2 Standard** (Compatibility) и Python 3.10+.
2. Откройте PowerShell в корне `Head of Train` и запустите сервер:

   ```powershell
   .\tools\serve.cmd
   ```

3. Откройте Godot → Import → `game/project.godot`. Дождитесь импорта ресурсов.
4. Нажмите **F5**: запустится вся игра. Откройте вкладку **«Профиль»**.

Окно PowerShell с сервером должно оставаться открытым. Клиент обращается к `http://127.0.0.1:8765`. Для другого сервера задайте `HEAD_OF_TRAIN_API` перед запуском редактора. Используйте F5, а не F6: отдельной сцене профиля нужны данные и навигация главной сцены.

## Пересборка браузерной версии после следующих правок

Из корня проекта в PowerShell (замените путь к Godot на свой):

```powershell
py -3 .\tools\export_web.py --project .\game --godot 'C:\Tools\Godot\Godot_v4.7.2-stable_win64_console.exe'
.\game\start.cmd
```

Экспорт использует шаблон из `tools/export_templates/` и обновляет `build/web`. После экспорта откройте http://127.0.0.1:8765/ и нажмите Ctrl+F5. Не открывайте `index.html` двойным щелчком: игре нужен HTTP-сервер и API.

## Управление профилем

- Наведение: плавная подсветка кнопок, навыков и достижений.
- Нажатие на достижение: условия получения и связанный рейс, если он сохранён.
- «Сохранённые разборы»: по одному рейсу или личному рекорду; кнопка открывает его настоящий отчёт с разбором решений.
- ← / →: предыдущая / следующая запись; Esc: закрыть окно; Tab / Shift+Tab и Enter: выбор и активация кнопок.
- На узком экране блоки идут вертикально и доступны прокруткой.
- Настройка уменьшения анимации в главном меню действует и на профиль.

Профиль показывает реальные очки сервера. Уровень и оценки «из 5» не выдумываются: сервер их не передаёт. Для двух пока не оцениваемых навыков отображается «Пока нет оценки». Вагон № 3 остаётся будущим контентом, даже если открыт в прогрессе.

Проверено здесь: нативный запуск и визуальная проверка на macOS в Godot 4.7.2, браузерный экспорт. Сам Windows в этой среде не запускался.

## Экран уведомлений

Экран обновлён по концепту. Карточки плавно выделяются и переключают подробности. ← / → выбирают событие, Tab и Enter управляют кнопками. На узком экране выбор карточки прокручивает к описанию. Настройка уменьшения анимации из главного меню учитывается.

Открытие вагона и награды требуют подтверждённого прогресса. Если рейсов ещё нет, показывается рекомендация для тренировки. Достижение может открыть связанный сохранённый разбор; «Рейс скоро» недоступен.

Проверено на Windows в Godot 4.7.2: 1280×720, 1024×768 и 360×640, нативная навигация с локальным сервером. Браузерная сборка обновлена после экрана уведомлений. Подробности и скриншоты: `docs/qa/notifications/verification.md`.
