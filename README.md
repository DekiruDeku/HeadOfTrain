# Начальник рейса — клиент А6, сервер Б6

**Обновлённый экран профиля:** [запуск на Windows со всеми изменениями](WINDOWS.md). Браузерная сборка обновлена; для запуска исходников откройте `game/project.godot` и нажмите F5 при работающем API.

Актуальный запуск и статус кандидата: [общий README](../README.md). Исправления А6 и новые реальные проверки: [verification.md](../docs/client/a6/verification.md). Б6 интегрирована; [новые проверки](../docs/qa/b6-integration/README.md). Ниже сохранён контекст предыдущих этапов; старые тесты и синтетические данные не заменяют результаты А6.

Клиент А5 подключён к Б5: отчёты, профиль, рекорды, достижения, рейтинги и уведомления. [Проверки](../docs/qa/b5-integration/README.md).

Состояние карточки А4, записанные пути и список оставшихся проверок после Б4: [документация А4](../docs/client/a4/README.md). Б4 интегрирован: багаж, дети, спор о месте, плед и столик. Клиент добавляет шесть пассажиров, переключение вагонов, различимые статусы, последствия и событие завершения.

Для готовой игры дважды нажмите `start.cmd` и откройте http://127.0.0.1:8765/. Нужен Python 3.10+. Окно сервера оставьте открытым. Скрипт использует соседние `backend/`, `build/web/`, `tools/`; одной папки `game/` для переноса игры недостаточно.

`game/` — основная версия клиента. Откройте `project.godot` в Godot 4.7.2 (Compatibility).
Главная сцена — `main.tscn`, компоненты — `scenes/*.tscn`, тема — `theme/train_theme.tres`.
Все визуальные узлы сохранены в сценах. Скрипты реализуют поведение и API v1; переходы и очки определяет сервер.

Из корня `Head of Train`:

```powershell
python .\tools\export_web.py --project .\game
.\tools\serve.cmd
```

Откройте http://127.0.0.1:8765/. Preset сохраняет результат в `../build/web/index.html`.
Инструмент экспорта устанавливает совместимый release-шаблон в пользовательский каталог Godot.
Старые копии в `.run/` не являются основным проектом.

В нативном запуске API: http://127.0.0.1:8765 или переменная `HEAD_OF_TRAIN_API`.
В Web API использует адрес страницы. Восстановление выполняется через localStorage и сервер;
неотправленное действие сохраняется с request_id и повторяется без изменения тела.

[Документация А2](../docs/client/a2/README.md), [передача следующей карточке](../docs/client/a2/B2-handoff.md).
Браузерные тесты: `../tools/qa/a2_browser_test.cjs`.
Старый `tests/a1_scene_test.*` сохранён как материал А1: он проверяет прежний локальный demo API,
несовместим с А2 и не является актуальным приёмочным тестом. Из Web-экспорта tests исключены.
`data/demo_requests.json` также сохранён, но игрой не используется.

`.godot/` — генерируемый кэш. Ограничения: одна активная вкладка, нет холодного старта без сети.


Новые попытки используют полный рейс Б4 (`full_b4`). Преобразование ответа в формат отображения — `scripts/crew_state.gd`; ID для отправки команд остаются серверными. Маршрутные точки Б3 сохранены в `scenes/fleet_map.tscn`. Существующие попытки Б1/Б2 восстанавливаются без конвертации.

Текущие проверки А5: `tests/a5_scene_test.tscn`, `tests/a4_scene_test.tscn`, `tests/b4_scene_test.tscn`, `../docs/client/a5/browser_test.cjs`. Синтетические данные прогресса не заменяют проверку Б5; `data/a5-preview.json` исключён из Web-сборки.
Результаты: [А5](../docs/client/a5/verification.md), [интеграция Б4](../docs/qa/b4-integration/README.md).
