# HeadOfTrain
# Начальник рейса — первый браузерный прототип

Минимальный проект на **Godot 4.7.2 / GDScript / Compatibility**. Стартовый экран показывает один вагон из `04-standard.png`. При загрузке игра проверяет API, а кнопка «Начать рейс» отправляет запрос и показывает полученный от сервера номер рейса.

## Открыть игру

После запуска сервера: **http://127.0.0.1:8765/**.

Готовый Web-экспорт находится в `build/web`. Открывать `index.html` двойным щелчком нельзя: WebAssembly загружается через HTTP.

## Запуск готовой сборки

Нужен Python 3.10 или новее, без дополнительных пакетов. Из корня проекта:

```powershell
python backend/server.py
```

Или `./tools/serve.ps1`. Для другого порта: `python backend/server.py --port 9000`. В Web-версии API автоматически использует текущий адрес страницы, поэтому порт менять в игре не нужно. Остановка сервера — `Ctrl+C` в его терминале.

## Редактирование и повторный экспорт

Открыть `game/project.godot` в Godot 4.7.2. Главная сцена — `game/main.tscn`, логика и адаптивный интерфейс — `game/main.gd`.

```powershell
./tools/export_web.ps1
# Если Godot установлен в другом месте:
./tools/export_web.ps1 -Godot 'C:\путь\Godot_v4.7.2-stable_win64.exe'
```

Скрипт импортирует ресурсы и выполняет release-экспорт. Также поддерживается переменная `GODOT_EXE`. Web-шаблон соответствующей версии уже сохранён в `tools/export_templates`. При смене версии Godot потребуется соответствующий шаблон.

Web-экспорт работает без потоков; PWA и service worker отключены. Сервер раздаёт только `build/web`, устанавливает MIME `application/wasm` и отключает кэширование для удобства разработки. После экспорта обновите вкладку браузера.

В редакторе игра обращается к `http://127.0.0.1:8765`; при необходимости задайте `HEAD_OF_TRAIN_API` перед запуском Godot.

## API

Игра и API обслуживаются одним процессом, с одного адреса. CORS не требуется.

| Запрос | Результат |
| --- | --- |
| `GET /api/health` | `200`, JSON с `ok: true`, названием сервиса и временем UTC |
| `POST /api/trips/start`, тело `{}` | `200`, JSON с `ok: true`, `status: "started"` и `trip_id` |

Ответ начала рейса, например:

```json
{"ok": true, "status": "started", "trip_id": "AE9E65"}
```

Это заглушка backend: номер создаётся для подтверждения обмена, рейсы не сохраняются. База данных, авторизация, сценарии и игровая симуляция в этот этап не входят.

Кнопка блокируется на время запроса. При ошибке соединения или некорректном ответе игра показывает ошибку и позволяет повторить запрос; тайм-аут — 8 секунд. Успех показывается только после получения и проверки ответа API.
