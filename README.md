# Начальник рейса — клиент А2

Этот каталог — Git-репозиторий Godot. Откройте `project.godot` в Godot 4.7.2 (Compatibility).
Главная сцена — `main.tscn`, компоненты — `scenes/*.tscn`, тема — `theme/train_theme.tres`.
Все визуальные узлы сохранены в сценах. Скрипты реализуют поведение и API Б1; переходы и очки определяет сервер.

Рабочее расположение: `Head of Train/.run/a1-work/game`. Внешний архив
`a2-head-of-train-external.zip` распаковывается непосредственно в `Head of Train`.
Из этой внешней папки выполните `tools\serve.cmd`, откройте http://127.0.0.1:8765/.
Повторный экспорт: `python tools/export_web.py --godot "C:/path/to/Godot_v4.7.2-stable_win64_console.exe"`.
Экспортный preset использует `../../../tools/export_templates/` и `../../../build/web/`.
При переносе репозитория в другую структуру измените эти два пути в настройках экспорта.

В нативном запуске API: http://127.0.0.1:8765 или переменная HEAD_OF_TRAIN_API.
В Web API использует адрес страницы. Восстановление выполняется через localStorage и сервер;
неотправленное действие сохраняется с request_id и повторяется без изменения тела.

Браузерные проверки А2: 20/20, финальный smoke 3/3 до переноса; свидетельства и скриншоты:
[документация А2](../../../docs/client/a2/README.md),
[передача следующей карточке](../../../docs/client/a2/B2-handoff.md).
Исходники теста: `../../../tools/qa/a2_browser_test.cjs`.
Старый `tests/a1_scene_test.*` сохранён как материал А1: он проверяет прежний локальный demo API,
несовместим с А2 и не является актуальным приёмочным тестом. Из Web-экспорта tests исключены.
`data/demo_requests.json` также сохранён, но игрой не используется.

`.godot/` — генерируемый кэш. Добавлен ignore; уже отслеживаемые файлы и ранее подготовленный
индекс Git сохранены. Не включайте изменения кэша в коммит А2.
Ограничения: одна активная вкладка, нет холодного старта без сети; GUI-инспекция редактора не завершена.
